# Learning Playwright 3X

Learning materials and practice work for JavaScript and Playwright testing.

## Repository structure

```text
chapter_00_Prompt_Engnieering/   Prompt engineering basics
chapter_01_Javascript Concepts/  JavaScript concepts and practice
chapter_02_JS_Concepts/          Additional JavaScript concepts
skills/                          Shared skills for coding assistants
```

## Shared skills

Repository-wide skills are stored under `skills/` so they can be reused by different coding assistants and development tools.

Each skill has its own directory and a `SKILL.md` entrypoint:

```text
skills/
└── skill-name/
    └── SKILL.md
```

Current skills:

- `git-workflow` — safe, platform-neutral Git collaboration practices.

When adding a skill, create a new lowercase kebab-case directory under `skills/` and add a concise `SKILL.md` containing its purpose, triggers, workflow, and safety rules.
